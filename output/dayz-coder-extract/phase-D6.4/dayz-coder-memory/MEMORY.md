# dayz-coder memory

Per-project feedback accumulated across sessions. Survives clones (it's in the repo, not in user-machine state).

- [enscript-ascii-only](feedback_enscript_ascii_only.md) — `.c` files must be ASCII-only; em dashes break the parser with confusing string-content errors.
- [enscript-single-line-calls](feedback_enscript_single_line_calls.md) — Don't split function-call arg expressions across lines; build a typed local variable first.
- [verify-class-before-modded](feedback_verify_class_before_modded.md) — Always search vanilla for class existence before writing `modded class X { ... }`.
